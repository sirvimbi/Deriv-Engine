==================================================
           DERIV ENGINE STANDALONE APP
==================================================

Welcome to Deriv Engine - Algorithmic Options Trader for macOS.

CONTENTS OF THIS FOLDER:
------------------------
1. Deriv Engine.app            -> The native macOS application.
2. Start_Deriv_Engine.command -> Double-click to automatically start the backend server & launch the app.
3. Stop_Deriv_Engine.command  -> Double-click to stop the backend server and close the app.

HOW TO RUN:
-----------
Option A (Easiest - 1-Click Launch):
- Double-click "Start_Deriv_Engine.command". It will launch the backend server and open the native app interface.

Option B (Manual App Launch):
- Ensure backend server is running (`cd backend && ./run.sh`), then double-click "Deriv Engine.app".

FEATURES:
---------
- Demo & Real Account Switching (Demo: VRTC tokens, Real: CR tokens).
- Real-time Equity & Balance Display.
- Digits Over/Under Strategy with Martingale & Loss Recovery.
- Complete strategy variable customizability.

Deriv Engine v1.0 Standalone macOS App
=====================================

HOW TO LAUNCH:
1. Double-click "Start_Deriv_Engine.command" to launch the Python backend and macOS Desktop application.
2. Enter your Deriv API token (Demo or Real account) in Settings or Dashboard.
3. Click "Start Trading" to run automated options strategies.

HOW TO STOP:
1. Double-click "Stop_Deriv_Engine.command" to stop the backend server and close the app.
